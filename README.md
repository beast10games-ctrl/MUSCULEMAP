# MUSCULEMAP

A minimal gym tracking web app with:
- 📅 Monthly calendar tracking
- 🔥 Streak system
- 🏋️ Workout selection
- 📊 Progress tracking

## Tech Stack
- HTML, CSS, JavaScript

## Features
- One-tap gym tracking
- Multi-select workouts
- Daily motivation
- Clean black & white UI
